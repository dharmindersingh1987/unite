You don't have an SSH key yet—only the known_hosts files are present.

Let's set one up. It only takes a couple of minutes.

Step 1: Generate an SSH key

Replace the email with the one associated with your GitHub account:

ssh-keygen -t ed25519 -C "your-email@example.com"

For example:

ssh-keygen -t ed25519 -C "dharmindersingh1987@gmail.com"

When prompted:

Enter file in which to save the key (/home/dharm/.ssh/id_ed25519):

Just press Enter.

When asked for a passphrase:

Enter passphrase (empty for no passphrase):
Press Enter for no passphrase (more convenient), or
Set a passphrase if you want extra security.
Step 2: Start the SSH agent
eval "$(ssh-agent -s)"

Then add your key:

ssh-add ~/.ssh/id_ed25519
Step 3: Copy the public key
cat ~/.ssh/id_ed25519.pub

Copy the entire output—it will start with:

ssh-ed25519 AAAAC3NzaC1...
Step 4: Add it to GitHub
Sign in to GitHub.
Go to Settings → SSH and GPG keys.
Click New SSH key.
Give it a name like Home Arch Linux.
Paste the copied key.
Save.
Step 5: Switch your repository to SSH

From your project directory:
git add .
git status
git commit -m "update xyz code"
git remote set-url origin git@github.com:dharmindersingh1987/unite.git

Verify it:

git remote -v

You should see:

origin  git@github.com:dharmindersingh1987/unite.git (fetch)
origin  git@github.com:dharmindersingh1987/unite.git (push)
Step 6: Test the connection
ssh -T git@github.com

The first time, you'll be asked to trust GitHub's host key. Type:

yes

If everything is set up correctly, you'll see a welcome message confirming authentication.

Step 7: Push your project
git push -u origin main
